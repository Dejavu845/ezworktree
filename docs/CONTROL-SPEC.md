# 掌控页读图（NODES-PLAN 刀 7）

图是读层。无 canvas。无第四主视图。点节点只换选中。

## 挂哪

掌控页：GaugeStrip 下右栏是工序条，左栏仍是来源。任务车道不画节点。

`来源 → 分支 → 检出 → 构建×n`

数字来自 `GET /api/graph`。选中分支时，条上写出该分支名；构建数只计该分支的 pin。

| 点 | 去哪 |
|---|---|
| 来源 | 检查器「清单」 |
| 分支 / 检出 | 全部分支 |
| 构建 | 检查器「清单」版本列 |

## 在岗卫星

最多一块。只列活 pulse，最多 5 条，按 `writtenAt` 新到旧。点进任务车道。无 pulse 则不画。不上板：产物版数、工序条。

## 检查器 / 森林

清单页签列版本并钉（仅人）。点构建时，当前分支的版本排在前面。森林行 tag：`n 版产物`。
