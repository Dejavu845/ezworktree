# 工区完整流程（人）

磁盘是真相。预览不直接碰 git；所有变更经引擎落地。Agent 不从这里启动。

## 进仓

1. 左下「+ 登记仓」给仓库最外面那一层。引擎种 `.lattice/`、wiki、HOLDINGS。还不是代码仓库时 toast 说人话。
2. 侧栏点项目。顶栏是仓名，不是产品口号。

## 看场

| 步 | 视图 | 人做什么 | 下一手 |
|---|---|---|---|
| 数 | 掌控 | 读四格：分支 / 树 / 任务 / 产物。点格进森林或车道。 | 有未检出 → 森林；要干活 → 车道 |
| 树 | 全部分支 | 上：工位甲板（只列出活 worktree）。下：全部分支表。点卡或行 = 选中。 | 对照里种树或复制路径 |
| 卡 | 任务车道 | 一行一任务。点行或 j/k 只选这张卡（不跟森林残留 lane 绑）。`+ 新任务` 组卡：意图、基线、允许路径、冻层理由。 | 对照创建 worktree |

工场皮肤只换地板和视差，不换这三步。

## 干一票（闭环）

对照工序条：卡 → 树 → 心跳 → 交接 → 完成。主按钮跟下一手。

1. **建卡**：功能名。先建卡，不种树。Toast：下一步创建 worktree。组卡条应收起。意图非法 / 基线空或不存在 / 拿自己的计划分支当基线说中文。
2. **种树**：对照「创建 worktree」。只复制打开配方（`cursor\|code\|open\|cd`），不 spawn。Toast 带「下一步登记心跳」。
3. **心跳**：写正在做（禁 %）。无 diff 点 `@sha` 或用默认 sha；有脏文件点源码行填 path。30 分钟过期。不是完成门禁。
4. **交接**：决定 + 下一步 → 生成。磁盘 `.lattice/handoffs/<taskId>.md`。再进交接页要能读回来。
5. **完成**：写完交接且对上现在的版本。`wiki.gate=block` 才改去把原文写进百科。warn/off 直接完成。

失败：toast 原文，对普通人说，不堆工程词。缺交接不能点完成。

## 百科

检查器「百科」。`/` 聚焦搜索。`2` 交接。对照 `n` 走下一手（不抢 j/k）。命中带字段 + snippet。点行就地展开。`[[wikilink]]` 可跳，找不到就改搜。raw 可点。收入原文中文标题各写各的 dest；同一天同标题撞车说中文。不是向量，不是第四视图。

## 给 Agent

复制路径 / 分支 / 配方。人在工区读。Agent 在自己的 worktree 写。不把工区当 IDE。

提示和注释对普通人说：不写 cite / sha / HEAD / ledger / slug / 对象 / 绝对路径。创建 / 归档 worktree 仍是动词。

## 不做

第四主视图 · 工位上假进度 % · 自动开 Cursor · 把流程写进仓内 `project.json`
