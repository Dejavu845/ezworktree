# 任务闭环（对照上的下一手）

人在工区里把一件活走完：建卡 → 树 → 心跳 → 交接 → 完成。不是第四主视图。磁盘契约不变。

## 读层

`taskLoop({ status, planted, pulse, handoff, wikiBlocked })` 只读。不写 `.lattice/`。

| 步 | 亮 | 下一手 |
|---|---|---|
| 卡 | 有任务 | — |
| 树 | 活 worktree | 对照里创建 worktree |
| 心跳 | 活 pulse | 登记心跳。无 diff 用 sha；点源码文件填 path |
| 交接 | 磁盘上有合法 v1 交接 | 写交接 |
| 完成 | `status=done` | 标记完成。百科还拦着就先去百科 |

心跳不是完成门槛。跳过心跳直接写交接，下一手变成交接 / 完成。`wiki.gate=block` 且交接原文还没写进百科时，完成步的动词是「写进百科」。归档后 `status=review`、树不在了：下一手是写交接（或完成），不再催种树。

## UI

对照页一条工序条，点步只换检查器页签或聚焦心跳。主按钮跟下一手走：未开树时只有「创建 worktree」，心跳盒不抢主按钮。交接页同一口径：下一手是种树时主按钮是「创建 worktree」，不是「生成交接」；闭环 hint 只出现一次，未开树不摊交接表单、也不写「没有交接文件就不能完成」。对照「路径」只写活 bay，不写仓根。`n` 跟主按钮同一手（不抢 j/k）。`/` 百科搜索，`2` 交接。全部分支甲板上，有任务的工位卡写「下一手 · 动词」；点卡仍停在全部分支，只把检查器切到对照。不是第四视图。

- 创建任务后提示「下一步：对照里创建 worktree」
- 种树后仍只复制配方，文案带「下一步登记心跳」
- 点源码文件：复制路径，并填 pulse cite
- 交接页读已有 `.lattice/handoffs/<taskId>.md`。没有写完交接不能点「标记完成」

## API

`GET /api/handoff?root=&task=` → `{ markdown, valid, path, prompt }`。POST 仍是生成。
