# 动效动词（交互，不是装饰）

动效挂在三主视图的读写上，不挂在宣传页。预览用 `motion` DOM / mini；不引 `motion/react`、Three.js、GSAP。Swift 壳只读同一套关闭条件（`motion: off` / 系统减弱）。

「高级」= 选中有去处、换页有方向、证据会呼吸。不是更多背景漂浮。

## 闭集

| 动词 | 触发 | 给人看 | 两皮肤 |
|---|---|---|---|
| `rise` | 列表/仪表进入 | 前 16 条短错开 | 都有 |
| `scene` | 掌控 ↔ 全部分支 ↔ 任务车道 | 按视图顺序左右 10px 淡入 | 都有 |
| `pane` | 检查器六页签 | 2px 上移淡入 | 都有 |
| `press` | 按钮、仪表、工序步、工位 | 按下 0.985，松手回弹 | 都有 |
| `receive` | 人选行 / 工位 / 在岗 | 检查器接住：左缘亮、页壳从右收入 | 都有 |
| `tick` | 证据格 `lit` 且 `doingFrom=pulse` | 格点慢闪；在岗有心跳时点一下 | 都有 |
| `depth` | 工场皮肤 · 中栏指针/滚动 | 远近层 + 工位局部光斑 | 仅工场 |

其它动词不加。`tick` 只跟磁盘证据/心跳，不跟自报 %。

## 方向

`holdings(0) → forest(1) → lanes(2)`。往右的视图从右侧进来，往左相反。换仓不走 `scene`，走现有 `rise`。

## 不做

第四主视图 · 假红绿灯 · hover 上浮（`translateY(-2px)`） · 行上 `press`（和工场行变换打架） · 劫持中栏滚动 · 把动效写进 `project.json`

`motion: off` / `prefers-reduced-motion`：全部动词停，深度变量清零。进行中的动画会停掉，并清掉写在元素上的透明度，避免页面停在看不见的状态。第一次打开不播放换页和列表进入，只有之后的切换才动。证据慢闪 2.4 秒，最暗到 0.55。
